# DreamRunner
### About the game
A runner game developed for **Shiba Arcade** with dream-like aesthetic. 
You control a child in the game and need to avoid the Shadows (obstacles) to have a good dream!
[Play it here!](https://jacio-m.itch.io/dreamrunner)

### About development
Most of the things were made by me, from the code to the pixelart, which took **81h 15m** to develop so far.
Some SFX were taken from free assets websites and the music was done by my friend (Takashi Lee).
It was really challenging because it was my first time actually trying to do a big game, so I had to learn godot from scratch.
